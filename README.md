This repository contains a two month delayed list of temporary disposable email addresses within the [Temp Mail Detector](http://tempmaildetector.com/?utm_source=github-blocklist) database. These are domains which our software has ranked as high risk, as well as domains which we have crawled for.

For an up to date database with real time analysis, [sign up](https://tempmaildetector.com/signup?utm_source=github-blocklist) for our email validation API. Our [documentation](https://tempmaildetector.com/documentation?utm_source=github-blocklist) provides an easy to follow guide on how to implement our API and gain access to real-time analysis.

### Data validity and corrections.
* Expired domains are systematically removed and re-evaluated to maintain a clean and reliable data set.
* If you believe a domain has been incorrectly classified, you can submit a correction request via the email listed on our website.
* Please send the request by an email on that domain as proof of ownership.
